# Automine — landing page

Landing page for **automine.com.br**: resource management and cost reduction (logistics and tax management), paid by commission on the savings generated. All site copy is in Brazilian Portuguese.

Every call to action leads to **WhatsApp (+55 11 91146-8466)** or **e-mail (vendas@automine.com.br)**. Messages are pre-filled with the context the visitor came from (the plan, service or simulation they picked).

It is a static site with no build step, no framework and no third-party requests: fonts are self-hosted and the illustrations are inline SVG.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000. Use a local server rather than opening the file directly, because browsers block web fonts on `file://`.

## Editing

- **Phone and e-mail**: change `CONTACT` at the top of `assets/js/main.js`. The same values also appear in the HTML as fallbacks for visitors without JavaScript, so search and replace `5511911468466` and `vendas@automine.com.br` in `index.html` as well.
- **Pre-filled messages**: each WhatsApp link has a `data-wa="…"` attribute holding its message. E-mail links use `data-mail-subject` / `data-mail-body`, where `&#10;` is a line break.
- **Plans and percentages**: the plan cards (`#planos`), the simulator radios (`data-rate`), the FAQ and the hero card all mention 15/25/30%. Update all of them together.
- **Colours and type**: the design tokens are at the top of `assets/css/styles.css` (`--gold-*`, `--violet-*`, `--bg-*`). Headings use Unbounded and body text uses Manrope.
- **Illustrations**: the low-poly mountains, stars and pine trees are generated by `tools/illustrations.py`, which writes them between the `<!--GEN:…-->` markers in `index.html`. Edit the specs in the script and run `python3 tools/illustrations.py`. Output is deterministic.

## Deploy (GitHub Pages + Registro.br)

`.github/workflows/deploy-pages.yml` publishes the site on every push to `main`. You can also run it by hand from the **Actions** tab. Only the public files are published: `index.html`, `404.html`, `assets/`, `robots.txt`, `sitemap.xml` and `site.webmanifest`.

One-time setup:

1. **GitHub → Settings → Pages**: under *Build and deployment*, set **Source** to **GitHub Actions**. In **Custom domain**, enter `automine.com.br` and save.
2. **Registro.br → automine.com.br → DNS → Editar zona**: add these records. Leave **Name** empty for the domain itself.

   | Type  | Name | Value                   |
   |-------|------|-------------------------|
   | A     |      | `185.199.108.153`       |
   | A     |      | `185.199.109.153`       |
   | A     |      | `185.199.110.153`       |
   | A     |      | `185.199.111.153`       |
   | AAAA  |      | `2606:50c0:8000::153`   |
   | AAAA  |      | `2606:50c0:8001::153`   |
   | AAAA  |      | `2606:50c0:8002::153`   |
   | AAAA  |      | `2606:50c0:8003::153`   |
   | CNAME | www  | `monolito123.github.io` |

3. When DNS has propagated (usually minutes, at most a few hours), GitHub issues a free HTTPS certificate. Then tick **Enforce HTTPS** in **Settings → Pages**. `www.automine.com.br` redirects to `automine.com.br` automatically.
4. Recommended: verify the domain in your GitHub account (**profile → Settings → Pages → Add a domain**). This adds one TXT record and stops anyone else from claiming `automine.com.br` on GitHub Pages.

Canonical URL, Open Graph image, `sitemap.xml` and `robots.txt` already point to `https://automine.com.br/`. To host elsewhere (Netlify, Vercel, cPanel…), upload those same public files.

## Before going live: please confirm

- **Plan details**: the brief defined only commission and support level (basic / full / premium). The bullet points under each plan and the process steps are suggested copy and should be checked with the commercial team.
- **Service tags** (fretes, créditos, enquadramento…): adjust them to the services actually offered.
- **Logo**: the mountain-and-gem mark is a placeholder brand mark. Swap it for the official logo if there is one (it appears in the header, footer, `assets/img/favicon.svg` and the icon PNGs).
- **Analytics**: none is installed. If you add any, update the form note ("Este site não armazena os seus dados") and consider a cookie notice (LGPD).

## Accessibility and performance

- Semantic landmarks, skip link, labelled form fields, keyboard-friendly menu (Esc closes it), visible focus.
- `prefers-reduced-motion` turns off every animation.
- Checked with axe-core at desktop and mobile widths: 0 violations.
- No horizontal overflow from 320 px to 1920 px.
